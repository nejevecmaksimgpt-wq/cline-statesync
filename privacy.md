# Privacy Policy

Cline StateSync is a personal-use application for synchronizing encrypted Cline state backups between the owner's computers.

## Google user data

Cline StateSync uses Google OAuth and the Google Drive API with the limited `drive.file` scope.

The application accesses only files and folders that it creates for its own synchronization process.

## Data usage

Google user data is used only to:

- upload encrypted Cline StateSync backups;
- download those encrypted backups;
- verify synchronization of files created by Cline StateSync.

The application does not sell, share, transfer, or disclose Google user data to third parties.

## Data storage

Cline StateSync stores only encrypted synchronization data in Google Drive.

OAuth credentials and application secrets are stored locally on the owner's computers and are not stored in this public GitHub repository.

## Personal use

Cline StateSync is intended only for use by the owner of the application.

## Contact

For questions about this application or its privacy practices, contact the application owner through the Google account used to authorize the application.
